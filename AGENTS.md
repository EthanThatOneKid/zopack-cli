# Markdown guidelines for agents

This repository maintains a strict style guide for markdown documentation to ensure readability, clean structure, and consistent formatting. All AI agents contributing to this codebase must adhere to the following rules when creating or updating markdown files:

## Heading guidelines

* **Use sentence case:** Only the first word and proper nouns (such as "Zo", "TypeScript", etc.) or code identifiers should be capitalized. Do not use title case for headings.
* **Keep headings concise:** Avoid long, verbose headings. They should be brief, informative, and to the point.
* **Do not use numbered headings:** Avoid prefixing headings with numbers (e.g., use `### Clone repository on local machine` instead of `### 2. Clone the repo on a local machine`). Use standard bullet points or ordered lists within the content if a step-by-step sequence is needed.

## Reference examples

### Correct heading style

```markdown
# Zopack CLI

## Local development tutorial

### Create space and repository in Zo
```

### Incorrect heading style

```markdown
# Zopack CLI

## Local Development Tutorial

### 1. Create the Space and Repo in Zo
```
